## 1. 命题逻辑

### 1.1 核心概念

| 概念 | 定义 | 示例 |
|------|------|------|
| **命题** | 能判断真假的陈述句 | "2是偶数"（真命题） |
| **原子命题** | 不可再分解的简单命题 | "今天下雨" |
| **复合命题** | 由原子命题+联结词构成 | "今天下雨 **且** 刮风" |
| **真值** | 命题的真(T/1)或假(F/0) | — |

### 1.2 五个基本联结词

| 联结词 | 符号 | 含义 | 真值条件 |
|--------|------|------|----------|
| 否定 | ¬ P | 非P | P为假时真 |
| 合取 | P ∧ Q | P且Q | P、Q同时为真才真 |
| 析取 | P ∨ Q | P或Q | P、Q至少一个为真即真 |
| 蕴含 | P → Q | 若P则Q | P真Q假时为假，其余为真 |
| 等价 | P ↔ Q | P当且仅当Q | P、Q同真或同假时为真 |

### 1.3 真值表（必背）

**蕴含的真值表（最容易出错）**：

| P | Q | P → Q |
|---|---|-----------|
| T | T | T |
| T | F | **F** ← 仅此行为假 |
| F | T | T |
| F | F | T |

> **理解**：「如果下雨，我就带伞」—— 如果没下雨（P=F），不管我带不带伞，这句话都没有被违反，所以为真。

### 1.4 重要逻辑等价式

| 名称 | 公式 |
|------|------|
| 双重否定律 | ¬¬ P ≡ P |
| 幂等律 | P ∧ P ≡ P；P ∨ P ≡ P |
| 交换律 | P ∧ Q ≡ Q ∧ P；P ∨ Q ≡ Q ∨ P |
| 结合律 | (P ∧ Q) ∧ R ≡ P ∧ (Q ∧ R) |
| 分配律 | P ∧ (Q ∨ R) ≡ (P ∧ Q) ∨ (P ∧ R) |
| **德摩根律** | ¬(P ∧ Q) ≡ ¬ P ∨ ¬ Q |
| | ¬(P ∨ Q) ≡ ¬ P ∧ ¬ Q |
| 吸收律 | P ∧ (P ∨ Q) ≡ P；P ∨ (P ∧ Q) ≡ P |
| 蕴含等价 | P → Q ≡ ¬ P ∨ Q |

### 1.5 推理规则

| 规则 | 形式 | 说明 |
|------|------|------|
| 假言推理 (MP) | P, P → Q ⇒ Q | 肯定前件 |
| 拒取式 (MT) | ¬ Q, P → Q ⇒ ¬ P | 否定后件 |
| 假言三段论 | P → Q, Q → R ⇒ P → R | 传递 |
| 析取三段论 | P ∨ Q, ¬ P ⇒ Q | 排除 |

### 1.6 例题

**例1**：证明 ¬(P → Q) ≡ P ∧ ¬ Q

> **解**：
> ¬(P → Q) ≡ ¬(¬ P ∨ Q) （蕴含等价）
> ≡ ¬¬ P ∧ ¬ Q （德摩根律）
> ≡ P ∧ ¬ Q （双重否定律）

**例2**：判断推理是否正确——"如果下雨，地就湿。地湿了，所以下雨了。"

> **解**：设 P=下雨，Q=地湿。
> 前提：P → Q, Q；结论：P
> 这是**肯定后件的谬误**。真值表验证：当 P=F, Q=T 时，P → Q 为 T，Q 为 T，但 P 为 F。推理无效。

## 2. 谓词逻辑

### 2.1 核心概念

| 概念 | 定义 | 示例 |
|------|------|------|
| **个体词** | 讨论的对象（主语） | 张三、5、x |
| **谓词** | 描述个体性质或关系的"谓语" | P(x)：x是偶数 |
| **量词** | 修饰个体范围的词 | ∀（全称）、∃（存在） |
| **全称量词 ∀** | "对所有…" | ∀x P(x)：所有x满足P |
| **存在量词 ∃** | "存在…" | ∃x P(x)：至少有一个x满足P |
| **论域** | 个体变元的取值范围 | 全体整数、全体实数 |

### 2.2 量词的否定（必背）

| 规则 | 公式 |
|------|------|
| 全称否定 | ¬∀ x P(x) ≡ ∃ x ¬ P(x) |
| 存在否定 | ¬∃ x P(x) ≡ ∀ x ¬ P(x) |

> **口诀**：否定穿过量词，量词翻转（∀↔∃），否定落到谓词上。

### 2.3 例题

**例3**：将"不是所有人都诚实"符号化，并写出其等价形式。

> **解**：
> 设论域为所有人，H(x)：x是诚实的。
> 原命题：¬∀ x H(x)
> 等价形式：∃ x ¬ H(x)（存在不诚实的人）

**例4**：写出 ¬(∀ x ∃ y P(x,y)) 的等价形式。

> **解**：
> ¬(∀ x ∃ y P(x,y))
> ≡ ∃ x ¬(∃ y P(x,y)) （量词翻转）
> ≡ ∃ x ∀ y ¬ P(x,y) （量词再翻转）

## 3. 集合论

### 3.1 核心概念

| 概念 | 记号 | 定义 |
|------|------|------|
| 集合 | A, B, C... | 确定对象的全体 |
| 元素 | a ∈ A | a是A的元素 |
| 空集 | ∅ | 不含任何元素的集合 |
| 全集 | U | 所讨论对象的全体 |
| 子集 | A ⊆ B | A中每个元素都在B中 |
| 真子集 | A ⊂ B | A ⊆ B 且 A ≠ B |
| 幂集 | P(A) 或 2^A | A的所有子集组成的集合 |
| 基数 | | A | | A中元素的个数 |

### 3.2 集合运算

| 运算 | 记号 | 定义 |
|------|------|------|
| 并集 | A ∪ B | {x \| x ∈ A ∨ x ∈ B} |
| 交集 | A ∩ B | {x \| x ∈ A ∧ x ∈ B} |
| 差集 | A - B | {x \| x ∈ A ∧ x ∉ B} |
| 补集 | ∼A 或 A̅ | {x \| x ∈ U ∧ x ∉ A} |
| 对称差 | A ⊕ B | (A - B) ∪ (B - A) |

### 3.3 集合恒等式

| 名称 | 公式 |
|------|------|
| 幂等律 | A ∪ A = A；A ∩ A = A |
| 交换律 | A ∪ B = B ∪ A；A ∩ B = B ∩ A |
| 结合律 | (A ∪ B) ∪ C = A ∪ (B ∪ C) |
| 分配律 | A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C) |
| **德摩根律** | ~(A ∪ B) = A̅ ∩ B̅ |
| | ~(A ∩ B) = A̅ ∪ B̅ |
| 吸收律 | A ∪ (A ∩ B) = A；A ∩ (A ∪ B) = A |

### 3.4 幂集的基数

若 |A| = n，则 |P(A)| = 2ⁿ

> **理解**：n个元素每个都有"选/不选"两种可能，所以共 2ⁿ 个子集。

### 3.5 例题

**例5**：设 A = {1, 2, 3}，求 P(A)。

> **解**：
> P(A) = {∅, {1}, {2}, {3}, {1,2}, {1,3}, {2,3}, {1,2,3}}
> |P(A)| = 2³ = 8

**例6**：用集合恒等式证明 (A ∩ B) ∪ (A ∩ B̅) = A

> **解**：
> (A ∩ B) ∪ (A ∩ B̅)
> = A ∩ (B ∪ B̅) （分配律，提取公因子A）
> = A ∩ U （互补律）
> = A

## 4. 关系

### 4.1 核心概念

| 概念 | 定义 |
|------|------|
| **有序对** | ⟨a, b⟩，有顺序的二元组 |
| **笛卡尔积** | A × B = {⟨a,b⟩ \| a ∈ A, b ∈ B} |
| **二元关系** | A × B 的子集 R，即 R ⊆ A × B |
| **定义域 dom(R)** | {a \| ∃b (⟨a,b⟩ ∈ R)} |
| **值域 ran(R)** | {b \| ∃a (⟨a,b⟩ ∈ R)} |

> 若 | A | = m, | B | = n，则 A 到 B 的不同关系有 2ᵐⁿ 个。

### 4.2 关系的性质（必考）

设 R 是集合 A 上的关系：

| 性质 | 定义 | 判别条件 |
|------|------|----------|
| **自反性** | ∀ x ∈ A, ⟨ x,x ⟩ ∈ R | 每个元素都有自环 |
| **反自反性** | ∀ x ∈ A, ⟨ x,x ⟩ ∉ R | 每个元素都无自环 |
| **对称性** | ⟨ x,y ⟩ ∈ R ⇒ ⟨ y,x ⟩ ∈ R | 边都是双向的 |
| **反对称性** | ⟨ x,y ⟩ ∈ R ∧ ⟨ y,x ⟩ ∈ R ⇒ x=y | 双向边只能是自环 |
| **传递性** | ⟨ x,y ⟩ ∈ R ∧ ⟨ y,z ⟩ ∈ R ⇒ ⟨ x,z ⟩ ∈ R | 两步能到的，一步也能到 |

### 4.3 闭包

| 类型 | 记号 | 含义 |
|------|------|------|
| 自反闭包 | r(R) | 添加最少有序对使R具有自反性 |
| 对称闭包 | s(R) | 添加最少有序对使R具有对称性 |
| 传递闭包 | t(R) | 添加最少有序对使R具有传递性 |

### 4.4 等价关系与偏序关系

**等价关系** = 自反 + 对称 + 传递

| 概念 | 定义 |
|------|------|
| **等价类** [a]_R | 与a有等价关系的所有元素的集合 |
| **商集** A/R | 所有等价类的集合 |

**偏序关系** = 自反 + 反对称 + 传递

| 概念 | 定义 |
|------|------|
| **偏序集** | 装备了偏序关系的集合，记作 ⟨ A, ≼ ⟩ |
| **哈斯图** | 偏序关系的简化表示图 |
| **最大/最小元** | 比所有元素都大/小的元素 |
| **极大/极小元** | 没有比它更大/更小的元素 |
| **上/下确界** | 最小上界 / 最大下界 |

### 4.5 例题

**例7**：A = {1, 2, 3}，R = {⟨1,2⟩, ⟨2,1⟩, ⟨1,1⟩, ⟨2,2⟩}。判断R是否具有自反性、对称性、传递性。

> **解**：
> - 自反性？⟨3,3⟩ ∉ R，**不具有**。
> - 对称性？⟨1,2⟩∈R→⟨2,1⟩∈R ✓；⟨2,1⟩∈R→⟨1,2⟩∈R ✓；自环也满足。**具有**。
> - 传递性？⟨1,2⟩∈R ∧ ⟨2,1⟩∈R → 需要⟨1,1⟩∈R ✓；⟨2,1⟩∈R ∧ ⟨1,2⟩∈R → 需要⟨2,2⟩∈R ✓。**具有**。

**例8**：设 A = {1, 2, 3, 4, 6, 12}，定义整除关系 D = {⟨x,y⟩ | x整除y}。画出哈斯图，指出极大元、极小元、最大元、最小元。

> **解**：
> 哈斯图分层：
> - 第1层（底层）：1（整除所有数）
> - 第2层：2, 3
> - 第3层：4, 6
> - 第4层（顶层）：12（被所有数整除）
>
> - **极小元**：1（唯一）
> - **极大元**：12（唯一）
> - **最小元**：1（极小元且唯一）
> - **最大元**：12（极大元且唯一）

## 5. 函数

### 5.1 核心概念

| 概念 | 定义 |
|------|------|
| **函数** | 特殊的关系：每个定义域元素对应**唯一**值域元素 |
| **f: A → B** | 定义域为A，值域含于B的函数 |
| **像** f(a) | 元素a在f下的函数值 |
| **原像** f⁻¹(b) | 函数值为b的所有定义域元素的集合 |

### 5.2 函数的分类（必考）

| 类型 | 定义 | 图示特征 |
|------|------|----------|
| **单射（入射）** | a₁ ≠ a₂ ⇒ f(a₁) ≠ f(a₂) | 不同元素映射到不同元素 |
| **满射** | ∀ b ∈ B, ∃ a ∈ A: f(a) = b | B中每个元素都有原像 |
| **双射（一一对应）** | 既是单射又是满射 | 完美配对 |

### 5.3 复合与逆函数

| 概念 | 公式/定义 |
|------|-----------|
| 复合函数 | (g ∘ f)(x) = g(f(x)) |
| 逆函数 f⁻¹ | 仅当 f 是**双射**时才存在逆函数 |

### 5.4 例题

**例9**：判断 f: ℝ → ℝ, f(x) = x^2 是否为单射、满射。

> **解**：
> - **单射？** f(2) = f(-2) = 4，不同元素映射到相同值，**不是单射**。
> - **满射？** 对 y = -1 ∈ ℝ，∄ x ∈ ℝ 使 x^2 = -1，**不是满射**。

**例10**：f(x) = 2x + 1 是否双射？若是，求逆函数。

> **解**：
> - 单射：f(x₁)=f(x₂) ⇒ 2x₁+1=2x₂+1 ⇒ x₁=x₂ ✓
> - 满射：对任意 y ∈ ℝ，取 x = (y-1)/2，则 f(x)=y ✓
> - **是双射**。
> - 逆函数：y = 2x+1 ⇒ x = (y-1)/2，即 f⁻¹(y) = (y-1)/2

## 6. 图论基础

### 6.1 核心概念

| 概念 | 定义 |
|------|------|
| **图 G = (V, E)** | V：顶点集，E：边集 |
| **无向图** | 边没有方向 |
| **有向图** | 边有方向 |
| **度 deg(v)** | 与顶点v关联的边数 |
| **握手定理** | 所有顶点度数之和 = 2 × 边数（∑ deg(v) = 2|E|） |
| **路径** | 顶点和边交替的序列 |
| **回路（环）** | 起点=终点的路径 |
| **连通图** | 任意两点间都有路径 |

### 6.2 图的矩阵表示

**邻接矩阵 A**：aᵢⱼ = 1 (若 vᵢ 与 vⱼ 相邻), 0 (否则)

> Aⁿ 的 (i,j) 元 = 从 vᵢ 到 vⱼ 长度为 n 的路径条数。

### 6.3 欧拉图与哈密顿图

| 类型 | 定义 | 判别条件 |
|------|------|----------|
| **欧拉通路** | 经过每条边恰好一次 | 恰有0或2个奇度顶点 |
| **欧拉回路** | 欧拉通路且起点=终点 | 所有顶点度为偶数 |
| **哈密顿通路** | 经过每个顶点恰好一次 | 无充要条件（NP完全问题） |
| **哈密顿回路** | 哈密顿通路且起点=终点 | 无充要条件 |

### 6.4 平面图

| 概念 | 公式/定义 |
|------|-----------|
| **欧拉公式** | v - e + f = 2（v顶点数, e边数, f面数） |
| **简单平面图** | e ≤ 3v - 6（v ≥ 3） |

### 6.5 例题

**例11**：判断下图是否存在欧拉回路或欧拉通路：

```
    B
   / \
  A---C
   \ /
    D
```

（K₄：4个顶点全连接，每顶点度=3）

> **解**：4个顶点度数都是3（奇数）。
> - 奇数度顶点有4个（>2），所以**不存在欧拉通路，更不存在欧拉回路**。

**例12**：用欧拉公式计算：若一个连通平面图有6个顶点、7条边，则有多少个面？

> **解**：由欧拉公式 v - e + f = 2
> f = 2 - v + e = 2 - 6 + 7 = 3
> 共3个面（包括外部无限面）。

## 7. 树

### 7.1 核心概念

| 概念 | 定义 |
|------|------|
| **树** | 连通且无回路的无向图 |
| **森林** | 若干个不相连的树 |
| **生成树** | 包含图G所有顶点的树（G的子图） |
| **最小生成树** | 带权图中权值之和最小的生成树 |
| **根树** | 指定一个根节点的有向树 |
| **m叉树** | 每个节点最多m个孩子 |
| **叶节点** | 度为1的节点（在根树中没有孩子的节点） |

### 7.2 树的性质（必背）

设 T 是有 v 个顶点、e 条边的树：

1. e = v - 1（树边数=顶点数-1）
2. 任何非平凡树至少有两个叶节点（度为1）
3. 树中任意两点间有唯一路径
4. 树是最小连通图（删任意一边就不连通）
5. 树是最大无回路图（加任意一边就产生回路）

### 7.3 最小生成树算法

**Kruskal算法**：每次选不构成回路的最小权边。

**Prim算法**：从任一顶点出发，每次选与当前树相连的最小权边。

### 7.4 例题

**例13**：一棵树有10个顶点，其中3个度为3，其余顶点度为1。问有多少个叶节点？

> **解**：设叶节点个数为 x。
> 树边数：e = v - 1 = 10 - 1 = 9
> 握手定理：∑ deg(v) = 2e = 18
> 又 ∑ deg(v) = 3 × 3 + x × 1 = 9 + x
> 9 + x = 18 ⇒ x = 9
> **共9个叶节点**。

**例14**：判断以下哪些图是树：(a) 5个顶点4条边的连通图；(b) 5个顶点5条边的无回路图。

> **解**：
> (a) 连通 + e=v-1 → **是树**
> (b) 无回路但 e=5 ≠ v-1=4 → 这不可能，无回路的图边数最多 v-1，矛盾 → **不是树**（实际上 e=5 > v-1 必然有回路）

## 8. 代数系统与布尔代数

### 8.1 核心概念

| 概念 | 定义 |
|------|------|
| **代数系统** | 集合 + 其上的运算，记作 ⟨ A, *₁, *₂, ... ⟩ |
| **半群** | 运算满足结合律的代数系统 |
| **幺半群（独异点）** | 有单位元（幺元）的半群 |
| **群** | 每个元素都有逆元的幺半群 |
| **交换群（阿贝尔群）** | 运算满足交换律的群 |
| **环** | 有两种运算（+、×），对+是交换群，对×是半群，且×对+可分配 |
| **域** | 环 + 非零元对乘法构成交换群 |

### 8.2 特殊元素

| 名称 | 定义 |
|------|------|
| **幺元（单位元）e** | e * a = a * e = a |
| **零元 0** | 0 * a = a * 0 = 0 |
| **逆元 a⁻¹** | a * a⁻¹ = a⁻¹ * a = e |

### 8.3 布尔代数

| 概念 | 定义/公式 |
|------|-----------|
| **布尔代数** | 有补分配格，记作 ⟨ B, ∧, ∨, ¬, 0, 1 ⟩ |
| **基本运算** | 与（∧）、或（∨）、非（¬） |
| **幂等律** | a ∨ a = a；a ∧ a = a |
| **互补律** | a ∨ ¬ a = 1；a ∧ ¬ a = 0 |

德摩根律在布尔代数中也成立：
- ¬(a ∨ b) = ¬ a ∧ ¬ b
- ¬(a ∧ b) = ¬ a ∨ ¬ b

### 8.4 例题

**例15**：验证 ⟨ ℤ, + ⟩ 是否构成群。

> **解**：
> - 封闭性：两整数之和仍为整数 ✓
> - 结合律：(a+b)+c = a+(b+c) ✓
> - 幺元：0（因为 a+0=0+a=a）✓
> - 逆元：对任意整数a，其加法逆元为 -a，因为 a+(-a)=0 ✓
> - **构成群**。又因为加法满足交换律 a+b=b+a，所以是**交换群**。

**例16**：简化布尔表达式 ¬(A ∧ B) ∨ (A ∧ ¬ B)

> **解**：
> ¬(A ∧ B) ∨ (A ∧ ¬ B)
> = (¬ A ∨ ¬ B) ∨ (A ∧ ¬ B) （德摩根律）
> = ¬ A ∨ ¬ B ∨ (A ∧ ¬ B)
> = ¬ A ∨ [¬ B ∨ (A ∧ ¬ B)]
> = ¬ A ∨ ¬ B （吸收律：¬ B ∨ (A ∧ ¬ B) ≡ ¬ B）

11. **证明**：
